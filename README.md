# Ledger — Personal Finance Tracker

Full CRUD expense/income tracker built with React + Vite + Recharts.

## Run it
```
npm install
npm run dev
```

## Features
- Add, edit, and delete transactions with inline validation
- Data persists to localStorage — refresh and it's still there
- Category breakdown (doughnut) and 6-month income/expense trend (bar), both live-updating
- Search, type filter, and category filter on the transaction list
